# ProtBed Benchmark Suite (v1.0.0)

Reproducibility notebooks comparing results produced by the ProtBed web application (https://protbed.com) with independent Python implementations on four public mass-spectrometry datasets.

ProtBed analyses quantified abundance tables (post-extraction feature matrices); it does not process raw MS/MS spectra. These notebooks re-implement selected analyses (preprocessing, differential testing, dimensionality reduction, mean-variance quality control, and supervised classification with stratified five-fold cross-validation) so that outputs can be compared numerically and visually.

## Repository structure

```text
protbed-benchmarks/
├── 01_plasma_ad_lipidomics/        Plasma lipidomics, Alzheimer's disease vs control
├── 02_urine_gcms_metabolomics/     Urine GC-MS metabolomics, Control / DM / DKD
├── 03_plasma_ev_proteomics/        Plasma extracellular-vesicle proteomics, Control / CP / IPMN / PDAC
└── 04_postmortem_tmt_proteomics/   Post-mortem substantia nigra TMT proteomics, PD vs HC
```

Each cohort folder contains:

| Path | Content |
|------|---------|
| `benchmark_*.ipynb` | Python benchmark notebook |
| `data/` | Input data table as published by the original authors |
| `protbed_outputs/` | Figures and tables exported from ProtBed |
| `python_outputs/` | Figures and tables generated by the notebook |

## Installation

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

Open a notebook from inside its cohort folder; input paths are relative to that folder (`data/...`).

## Notes

- Sample labels follow upload-column order and do not imply group order.
- Classification metrics are computed from out-of-fold predictions (stratified five-fold cross-validation), not in-sample fits.
- Differences between ProtBed and Python outputs can arise from random seeds, tie handling in rank tests, and percentile definitions.
